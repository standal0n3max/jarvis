# Траты

Один расход — один новый файл. Месячный журнал и скрипты не использовать: `exec` выключен.

## Куда писать

1. `inbox/YYYY-MM-DD-HHMM-кратко.md` — сырой вход.
2. `finance/YYYY/YYYY-MM-DD-кратко.md` — постоянная копия.

Дата в имени постоянной папки — дата траты. `YYYY` — год этой даты.

## Frontmatter

```yaml
type: expense
date: YYYY-MM-DD
amount: 1200
currency: RUB
category: быт
method: cash
source: text
```

- `method`: `cash` (нал, наличные) или `card` (карта).
- `source`: `text`, `voice` или `photo`.
- Валюта без явного названия — `RUB`.
- Сумма — число, без пробелов и без знака валюты.

## Когда не создавать файл

Один вопрос и стоп:

- нет суммы;
- нет даты и нет слов «сегодня», «вчера», «завтра»;
- неясна категория;
- неясно, нал или карта;
- с фото не читается сумма.

Категорию не подставлять молча. Если слово траты само её задаёт (кофе, химчистка), записать эту категорию коротко по-русски.

Уже существующий файл траты не переписывать и не удалять без явного «да».
