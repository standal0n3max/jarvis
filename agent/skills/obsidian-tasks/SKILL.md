# Задачи

Одна задача — один новый файл плюс одна строка на доске. Скрипт установки доски не запускать: доска уже есть, `exec` выключен.

## Куда писать

1. `inbox/YYYY-MM-DD-HHMM-кратко.md` — сырой вход.
2. `tasks/YYYY-MM-DD-кратко.md` — дата в имени это дедлайн, если он назван, иначе дата создания.
3. Строка в `tasks/Board.md` в колонке, которая совпадает со `status`.

## Frontmatter

```yaml
type: task
status: todo
priority: P2
created: YYYY-MM-DD
due: YYYY-MM-DD
```

- `status`: `backlog`, `todo`, `in-progress`, `done`.
- Колонки доски: Backlog, Todo, In Progress, Done. Колонки Review нет.
- `priority`: `P1`, `P2`, `P3`. Если приоритет не назван — `P2`.
- «до начала <месяца>» — первый день этого месяца. «до начала ноября» в 2026 году = `2026-11-01`. «завтра» — следующий календарный день. Эти фразы уже задают дату: файл создавать, дату не спрашивать.
- Если дедлайн не назван и его нельзя вывести из такой фразы — один вопрос и файл не создавать.

Строка доски:

```markdown
- [ ] [[YYYY-MM-DD-кратко]] 🟡 P2 @{YYYY-MM-DD}
```

`P1` — 🔴, `P2` — 🟡, `P3` — 🟢. Для `done` чекбокс `[x]`.

При переносе меняются и строка на доске, и `status` в файле задачи. Другие заметки не переписывать. Удаление только после явного «да».

Встреча с часом в `tasks/` не создаётся. Её место — Google Calendar.
