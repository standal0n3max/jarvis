# Правила записи

Один тип сообщения — один новый файл. Сначала файл в `inbox/`, затем копия в постоянную папку. Уже существующие заметки не переписывать и не удалять, пока в Telegram нет явного «да». Сумму, дату и категорию не выдумывать: если поля нет, один уточняющий вопрос и файл не создавать.

Встреча с часом пишется только в Google Calendar. В `tasks/` её не дублировать.

## Куда класть

| Сообщение | Папка | Имя файла |
|---|---|---|
| Сырой вход | `inbox/` | `YYYY-MM-DD-HHMM-кратко.md` |
| Трата | `finance/YYYY/` | `YYYY-MM-DD-кратко.md` |
| Задача | `tasks/` | `YYYY-MM-DD-кратко.md` (дата дедлайна, иначе дата создания) |
| Идея | `ideas/` | `кратко.md` |
| Фильм | `media/movies/` | `название.md` |

`tasks/Board.md` — доска. Колонки: Backlog, Todo, In Progress, Done. Новая задача — новая строка в колонке, совпадающей со `status`. При переносе меняются и строка, и `status`.

## Обязательные поля

Трата:

```yaml
type: expense
date: YYYY-MM-DD
amount: 350
currency: RUB
category: еда
method: cash
source: text
```

`method`: `cash` (нал) или `card` (карта). `source`: `text`, `voice` или `photo`. Валюта без явного названия — `RUB`.

Задача:

```yaml
type: task
status: todo
priority: P2
created: YYYY-MM-DD
due: YYYY-MM-DD
```

`status`: `backlog`, `todo`, `in-progress`, `done`. `priority`: `P1`, `P2`, `P3`. Если приоритет не назван — `P2`.

Идея и фильм: `type` (`idea` или `movie`) и `created`. `status`, `priority`, `due` писать только если они названы.

## Что спросить

Один вопрос, без файла:

- нет суммы;
- нет даты и нет слов «сегодня», «вчера», «завтра»;
- неясна категория;
- с фото не читается сумма.

«Сегодня», «вчера» и «завтра» считаются от даты сообщения. Неясный способ оплаты — спросить «нал или карта?».

«До начала ноября» — это 1 ноября. В 2026 году это `2026-11-01`. Это известная дата, не повод для вопроса.

## Что можно только читать

Архив и папки с доступами владелец дописывает в этот файл сам. Агент их не пополняет и не правит.

Новые идеи — в `ideas/`. Новые фильмы — в `media/movies/`.

`system/AGENTS.md` можно читать. Менять его только после явного «да».
